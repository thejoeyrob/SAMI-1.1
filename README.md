# SAMI v1.2.0 — Cinematic Field Release

SAMI is an installable site-planning PWA for field teams who need professional drawing output without CAD experience.

## Launch experience
- A user gesture starts the cinematic sequence so iPad/iPhone/desktop browsers can reliably play the high-quality impact/electrical sound design.
- The camera follows the SAMI pin from the sky into a destructive ground impact, pulls back over fragmented green-lit cracks, retracts that energy, raises the pin and projects a CAD plan across a perspective ground plane.
- The pin resolves into the SAMI wordmark, followed by a restrained electrical trace.
- `Start planning` opens the workspace. `Why ask SAMI?` opens the narrated sales presentation inside the same PWA.

## Field workflow
- Mobile/tablet browser sessions are installation-only; the workspace opens from the installed PWA.
- The complete sidebar collapses/restores as one unit.
- Site Plan master tools remain compact at the top; full-width asset categories minimise scrolling.
- Selection, move, rotate, resize, points, grouping, replacement and live style controls remain available.
- Explore mode supports map-only note/photo field evidence, with an explicit option to include it on issued drawings.
- Public mapped gas, water, electricity, drainage, telecom and overhead-line information is available where the bounded reference query returns it. All service data is presented as planning guidance and must be verified with current asset-owner records and site locating before work.

## Deployment
Upload the deployable root files to the repository root. GitHub Pages can publish the repository using the included workflow.
